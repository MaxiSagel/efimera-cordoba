# EFÍMERA CÓRDOBA · web 2027 (borrador)

Web estática del festival EFÍMERA CÓRDOBA, en español (raíz) e inglés (`/en/`).

- Las páginas `.html` se generan con `python build.py`.
- El dosier en PDF (`assets/dosier/`) se genera con `python dosier.py` (necesita Google Chrome y PyMuPDF).

Versión de trabajo: las cifras de 2026 y las bases del premio son provisionales, y los formularios no envían datos todavía. `robots.txt` pide a los buscadores que no indexen esta versión.
